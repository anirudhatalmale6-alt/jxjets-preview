# jxjets — aircraft marketplace, working preview

Live: https://anirudhatalmale6-alt.github.io/jxjets-preview/

A working preview of an aircraft marketplace: a masonry listing grid, filters that
actually filter, a detail sheet, an embedded motion showcase and a feedback section.
No framework, no build step, no web font, no tracking.

## What is on the page, and what is deliberately not

The inventory is **demonstration data**. Every aircraft, price, location, reference
and review is generated by `gen_data.py` from a fixed seed.

The source spreadsheet this project started from holds 5 415 real listings scraped
from Sandhills (Controller.com / Trade-A-Plane). **None of it is published here**:
not a listing description, not a photograph, not a seller's name, not a telephone
number. Those belong to the sellers and to Sandhills.

What is reused is the *vocabulary* — the set of (category, manufacturer, model)
triples, because an aircraft type name is a public product name rather than listing
content. The file that holds that vocabulary (`_types.json`) is **not published in
this repo**, so `gen_data.py` will not run here as-is; `assets/data.js` is committed
instead, which is all the page needs.

Two facts worth keeping in view for the real build:

* the source file has **no price column at all** — every price here is invented;
* every photo in it hotlinks `media.sandhills.com`, so a production site must carry
  its own imagery for inventory it holds the rights to publish.

## Files

    index.html          the page
    assets/style.css    one stylesheet
    assets/app.js       filtering, masonry rendering, detail sheet, feedback form
    assets/data.js      generated demonstration inventory (74 aircraft)
    gen_data.py         the generator (needs the unpublished vocabulary file)
    src/checks.py       the automatic check suite

## Checks

    python3 src/checks.py                      # against the published page
    python3 src/checks.py http://127.0.0.1:8000/

61 checks. They run against the published URL rather than a local copy, and they
are written to be able to fail: they assert that the category filter *reduces* the
grid, that an impossible search empties it, that price sorting is genuinely ordered,
that helicopters are not drawn as aeroplanes, that the review cards are all marked
as templates, and that the demonstration banner is still on the page.

The suite does **not** assert "no third-party requests" — the Motion section embeds
four animations from hakimadjaoudi.com on purpose, so that claim would be false. It
checks those four still answer 200 instead.
